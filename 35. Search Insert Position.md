```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        if target <= nums[0]:
            return 0
        if target > nums[-1]:
            return len(nums)
        if target == nums[-1]:
            return len(nums) - 1
            
        def search_insert_helper(start_index, end_index):
            if start_index >= end_index:
                return
            mid = (start_index + end_index) // 2
            if nums[mid] == target:
                return mid
            if nums[mid] < target < nums[mid+1]:
                return mid + 1
            left = search_insert_helper(start_index, mid)
            right = search_insert_helper(mid+1, end_index)
            if left is not None:
                return left
            return right

        return search_insert_helper(0, len(nums) - 1)
```

端の探索が上手くできずで無理やり通した感。

二分探索に苦手意識があるのでしっかり書けるようになりたい。

## Step3

### 3回連続で再現できるようになる

書くのは2分くらい。

書くよりも脳内で動かすほうが時間かかる。

```python
class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        low = 0
        high = len(nums)
        while low < high:
            middle = (low + high) // 2
            if nums[middle] < target:
                low = middle + 1
            else:
                high = middle
        return low
```
