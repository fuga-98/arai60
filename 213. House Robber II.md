## Step1

### 思考ログ

円環になっているとのこと。

愚直なら、最初を含む最大値と含まない最大値を出してやればいけそう。

nums = (1,2,3,1) の場合、1,2,3 と2,3,1 の大きい方が答えになりそう。

時間、空間ともにO(n) nは100程度なので100 / 1,000,000 = 0.1ms くらい

関数化したほうが、この場合は分かりやすそう。

```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        if not nums:
            return 0
        if len(nums) == 1: # これでエラー
            return nums[0]
        return max(self.get_max_money(tuple(nums[:-1])), 
                    self.get_max_money(tuple(nums[1:])))
    
    @cache
    def get_max_money(self, nums: Tuple[int], index: int=-1) -> int:
        if not nums:
            return 0
        length = len(nums)
        if index < 0:
            index = length + index
            assert index >= 0
        if index >= length:
            index = length - 1
        
        if index == 0:
            return nums[0]
        if index == 1:
            return max(nums[0], nums[1])
        candidate = self.get_max_money(nums, index-2) + nums[index]
        return max(self.get_max_money(nums, index-1), candidate)
        
```

## デコレータとは

https://docs.python.org/ja/3.13/reference/compound_stmts.html#function-definitions

`@f1(arg)
@f2
**def** func(): **pass**`

は、だいたい次と等価です

**`def** func(): **pass**`

`func = f1(arg)(f2(func))`

ただし、前者のコードでは元々の関数を `func` という名前へ一時的に束縛することはない、というところを除きます。

https://docs.python.org/ja/3.13/library/functools.html#functools.wraps

ここは大事そう。
VSCodeとかでwrapperのdocstringが出るようになるのは嫌だなという感じ

```python
cache = {}

def my_cache(f):
    # global cache  これはいらない
    cache = {} # これなくてWA
    @wraps(f)
    def wrap(*args, **kwargs): # 引数がタプル or 辞書形式になる
        kw_items = tuple(sorted(kwargs.items()))
        key = (args, kw_items) # args と kwargs から一意なキーを作成
        if key in cache:
            return cache[key]
        cache[key] = f(*args, **kwargs)
        return cache[key]
    return wrap

class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return max(nums, default=0)

        @my_cache
        def get_max_amount(begin: int, end: int) -> int:
            length = end - begin
            if length == 1:
                return nums[begin]
            if length == 2:
                return max(nums[begin], nums[begin + 1])
            return max(nums[end - 1] + get_max_amount(begin, end - 2),
                                       get_max_amount(begin, end - 1))

        return max(get_max_amount(0, len(nums) - 1),
                   get_max_amount(1, len(nums)))
        
```

## Step3

### 3回連続で再現できるようになる

https://docs.python.org/ja/3.13/tutorial/controlflow.html#more-on-defining-functions

cacheを3回書いた。

```python
def my_cache(user_function):
    cache = {}
    
    @wraps(user_function)
    def wrapper(*args, **kwds):
        sorted_kwds = sorted(kwds.items())
        key = (args, tuple(sorted_kwds))
        if key not in cache:
            cache[key] = user_function(*args, **kwds)
        return cache[key]
    
    return wrapper

class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) <= 1:
            return max(nums, default=0)

        @my_cache
        def get_max_amount(begin: int, end: int) -> int:
            length = end - begin
            if length == 1:
                return nums[begin]
            if length == 2:
                return max(nums[begin], nums[begin + 1])
            return max(nums[end - 1] + get_max_amount(begin, end - 2),
                                       get_max_amount(begin, end - 1))

        return max(get_max_amount(0, len(nums) - 1),
                   get_max_amount(1, len(nums)))
```

my_cacheは関数宣言の時に一度だけ走る。呼び出されたときはwrapperが動く。
