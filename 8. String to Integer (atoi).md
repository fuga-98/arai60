## Step1

### 思考ログ

https://leetcode.com/problems/string-to-integer-atoi/

オートマトンっぽいなと思いました。O(N)

```python
MAX_INT32 = 2 ** 31 - 1
MIN_INT32 = - 2 ** 31
class Solution:
    def myAtoi(self, s: str) -> int:
        if not s:
            return 0
        i = 0
        while i < len(s) and s[i] == ' ':
            i += 1
        if i >= len(s): # ここなくてエラー
            return 0
        signedness = 1
        if s[i] == '+':
            i += 1
        elif s[i] == '-':
            signedness = -1
            i += 1
        num = 0
        while i < len(s):
            if s[i] not in string.digits:
                break
            num = num * 10 + int(s[i])
            i += 1
        num *= signedness
        num = min(num, MAX_INT32)
        num = max(num, MIN_INT32)
        return num
```

ほぼそのまま実装しただけ。

MAX_INT32 =  -(MIN_INT32 + 1)
class Solution:
    def myAtoi(self, s: str) -> int:
        def calc_int(total, c, sign):
            assert c in string.digits
            digit = ord(c) - ord('0')
            if sign == 1:
                if total > (MAX_INT32 - digit) / 10:

                return total * 10 + digit
